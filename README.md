# Alt3GDPS

Сайт сообщества и будущая панель управления GDPS.

## Текущий статус
Сейчас проект содержит статическую главную страницу. Она не создаёт и не хостит игровые серверы Geometry Dash.

## Публикация сайта
GitHub Pages может публиковать статические файлы из репозитория. Для бесплатного GitHub Pages репозиторий должен быть публичным.

1. Открой **Settings → Pages**.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку `main` и папку `/(root)`, затем нажми **Save**.
4. После публикации сайт будет доступен по адресу `https://djdhsvsbdb-design.github.io/Alt3GDPS/`.

См. [официальную инструкцию GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
